

# Play to Stealth Bastard

This game can teach kids how to write scripts that require waiting and timing.

It can also teach kids how to write scripts as small pieces of code that can be triggered by a human, instead of building a big application.

More about Stealth Bastard:
https://github.com/EloiStree/PlayTo_StealthBastard

The workshop consists of displaying four games on a big screen and asking learners to get as far as they can in each game using code.

Playing with human hands is forbidden; only code is allowed.

Learners are only allowed to trigger sequences of scripts.

The challenge is for each group to get as far as possible in the game without using their hands to play.
