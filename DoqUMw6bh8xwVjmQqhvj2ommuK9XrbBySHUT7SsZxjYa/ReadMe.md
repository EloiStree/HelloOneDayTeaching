
# Learn to Simulate a Gamepad with AmaZoo

> https://github.com/EloiStree/PlayTo_AmaZoo

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/459c35ae-1243-4cd5-890f-71c48e8c2166" />

The aim of this workshop is to learn how to simulate an Xbox gamepad using XInput and code to move in a game.

This workshop helps learners practise executing sequences of actions through code and start learning how to store, manage, and replay sequences and macros.

AmaZoo is a Belgian game that consists of puzzles involving sequences of actions.
