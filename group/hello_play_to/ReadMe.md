# Play To ...

> The Concept of Play To Is Simple: Learn to Code by Playing Real Video Games

I display games on screen that learners can buy and play after the workshop.
I can display one game for teamwork or four games (using four mini PCs) on screen for pair-programming groups.

I prepare a video for students showing them how to hack the game inputs themselves after the workshop. I then prepare the necessary hardware or software so that students can focus on learning to code rather than on the hacking process.

To interact with the games, students send network messages to an input simulator using UDP or WebSockets. This means that these workshops can be delivered using any programming language or game engine.

For kids, it is better to run these workshops using Python or GDScript in Godot.
For game developers who want to learn C#, it is better to use Unity or Godot.

For every game I use for teaching, I provide an input map on GitHub. You can find them here:
- https://github.com/EloiStree?tab=repositories&q=play+to&type=&language=&sort=

## The Basic Process for a One-Week Workshop

The workshop starts with the following games:

- 10 Seconds Ninja
- Stealth Bastard
- AmaZoo
- Hordes.io
- Choose Your Own Game

## For Programmers Who Already Understand Object-Oriented Programming

- Liftoff with telemetry
- Hordes.io with Tampermonkey

## For Programmers Looking for a Challenge

- Play Arc Raiders using a virtual reality headset.
- Play World of Warcraft using a virtual reality headset.
- Hunt for cheaters in World of Warcraft.
