# Learn to Code with 10 Seconds Ninja

> https://github.com/EloiStree/play_to_10_second_ninja

The aim of this workshop is to teach learners what variables and functions are by playing a game called *10 Seconds Ninja*.

For kids, this workshop is done in Python and Godot GDScript, but it can be given in any programming language.

<img width="460" height="215" alt="image" src="https://github.com/user-attachments/assets/2d79ad69-0b74-482e-a7a8-67d173ff0e23" />

When learners can finish a level in the best time they can achieve, they can move on to another game on another day: *Stealth Bastard*.

https://github.com/EloiStree/PlayTo_StealthBastard

This game helps them learn how to write code by progressing through levels.
