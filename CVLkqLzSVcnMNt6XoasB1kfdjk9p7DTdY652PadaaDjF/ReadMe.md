This workshop is for advanced learners.

Challenge of the workshop: Make the champion in the game Horde.io follow a road in the game.
Challenge for senior learners: Apply Dijkstra's algorithm to your code to navigate through paths.

This workshop is designed to explore the concept of imperfection in code.
Read the data from a game and apply inputs with some delay between them. Make the rotation imperfect.
This exercise is a good way to check whether the learner has the skills needed to work in the video game industry.

Moving a player along a path is a classic implementation in video games. It requires some coding, algorithmic logic, and rotation handling.

If you can complete this exercise, you have the basic skills needed for an internship at a video game studio. (At the very least, you can start contacting studios!)
